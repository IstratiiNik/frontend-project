# Meetup Events Platform

A modern platform for discovering and joining events. Inspired by Meetup, this project provides a user-friendly interface to search for events by interests, categories, and location.

## 🚀 Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/IstratiiNik/frontend-project.git
   cd frontend-project
   ```
2. Open `index.html` in your browser or use Live Server.
